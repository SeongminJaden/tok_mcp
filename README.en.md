# tok_mcp

[한국어](https://github.com/SeongminJaden/tok_mcp/blob/main/README.md) · [English](https://github.com/SeongminJaden/tok_mcp/blob/main/README.en.md)

tok_mcp drafts a cloud architecture from a workload type and an expected daily user count. It returns two files: `ARCHITECTURE.md` for design review and `.ai-context.yaml` for coding tools.

## Use from Node.js

```sh
npm install tok_mcp
```

```js
import { designArchitecture, generateArchitectureDocs } from "tok_mcp";

const design = designArchitecture({
  platform: "aws",
  serviceType: "saas",
  description: "TeamNotes",
  dau: 500,
  monthlyBudget: 150,
});
const files = generateArchitectureDocs(design);
console.log(files["ARCHITECTURE.md"]);
```

Your application chooses where to save the files. You can edit the design object and render it again. [Starter example that writes both files](https://github.com/SeongminJaden/tok_mcp/blob/main/examples/starter.mjs)

## Connect Cursor or Claude Desktop

Add this entry to your MCP settings. Call `design_architecture` for an initial design and pass an edited design to `generate_docs`. Both tools return file contents in `structuredContent.files`. Generated design prose is in Korean.

```json
{
  "mcpServers": {
    "tok_mcp": { "command": "npx", "args": ["-y", "tok_mcp@0.2.0"] }
  }
}
```

## Read the estimate

The AWS Seoul example costs $95.56 per month for the components shown. It runs one ARM Fargate task, one RDS PostgreSQL instance and one Redis node for 730 hours. Traffic charges and tax are extra. [단가표 / Price sheet](https://github.com/SeongminJaden/tok_mcp/blob/main/PRICING.md)

If you read YAML generated by 0.1.x, check your field paths against the example before upgrading. The new format has `schema_version: 2` and labels the draft `status: proposed`.
